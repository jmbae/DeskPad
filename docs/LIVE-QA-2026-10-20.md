# DeskPad 실제 Mac 연결 QA — 2026-10-20

## 검증 기준

검증 대상은 후속 [PR #5](https://github.com/nedpark/DeskPad/pull/5)와 [PR #6](https://github.com/nedpark/DeskPad/pull/6)를 통합한 로컬 `main`의 `845534a`다. 원격 `main`에는 PR을 병합하지 않았다. 이전 점검 내용은 [2026-10-19 통합 기록](READINESS-2026-10-19.md)에 보존한다.

Mandu Store iPad 시뮬레이터(iPadOS 26.5)에서 DeskPad를 실행해 실제 Mac 화면 공유 서버의 6016 × 3384 화면에 연결했다. 아래 결과는 시뮬레이터에서 확인한 것으로, 실물 iPad 검증을 대신하지 않는다. 저장된 연결의 Keychain 접근에는 ad-hoc 서명한 시뮬레이터 빌드를 사용했다. 재현 빌드 명령은 [TESTING.md](TESTING.md)에 있다.

## 실제 연결에서 확인한 동작

| 항목 | 결과 | 확인 내용 |
| --- | --- | --- |
| 실제 Mac 연결 및 화면 수신 | 통과 | 인증 후 실제 데스크톱 화면 표시 |
| 왼쪽 클릭 | 통과 | 원격 Spotlight 열기 확인 |
| ASCII 입력·Backspace·Enter | 통과 | Spotlight에서 입력 및 수정 후 TextEdit 실행 |
| 소프트웨어 한글 키보드 | 통과 | 입력한 `한글 입력 테스트`가 실제 Mac TextEdit에 표시됨 |
| 드래그 | 보류 | 최종 확인 전에 로컬 Mac이 잠김 |
| 오른쪽 클릭 | 보류 | 최종 확인 전에 로컬 Mac이 잠김 |
| 재접속 | 보류 | 최종 확인 전에 로컬 Mac이 잠김 |

보류 항목은 성공으로 판단하지 않는다. 로컬 Mac 잠금을 해제한 뒤 드래그, 오른쪽 클릭, 연결 종료 후 재접속 및 재접속 후 입력을 이어서 확인해야 한다.

## 자동 검증과 빌드

- UIKit 입력 테스트 17개 통과: XCTest 8개와 Swift Testing 9개.
- 실제 loopback TCP 세션 시나리오 13개 통과.
- 프로젝트의 원래 iOS 27 deployment 설정을 유지한 최신 Release 기기 빌드 `BUILD SUCCEEDED` 확인.
- Release 빌드 로그: `/tmp/deskpad-final-release.log`.
- 산출물: `build/DerivedData/Build/Products/Release-iphoneos/DeskPad.app`.

Release 기기 산출물은 unsigned 빌드이며, 실물 기기에 설치 가능한 서명 패키지나 TestFlight 배포물은 아니다.

## 남은 성능 문제

실제 6016 × 3384 화면의 Raw 프레임 수신에서 약 14~20초 지연이 남아 있다. 입력 패킷 전송과 화면 갱신은 별개이므로, 화면 변화가 늦게 보이는 현상을 곧바로 입력 미전송으로 판단하면 안 된다. 현재 입력 동작 확인과 별도로 고해상도 화면 전송 성능 개선이 필요하다.
